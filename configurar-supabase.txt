COMO FAZER O CADASTRO DE ATIVIDADES FUNCIONAR NO GITHUB PAGES
==============================================================

O GitHub Pages só serve arquivos estáticos, então ele NÃO roda o Node.js
nem o MySQL. Por isso o site agora usa o SUPABASE (gratuito) como banco
de dados. As imagens são guardadas direto na tabela (em base64), então
NÃO é preciso criar bucket no Storage. Siga os passos abaixo UMA vez.


1) CRIAR A CONTA E O PROJETO
----------------------------
1. Entre em https://supabase.com e clique em "Start your project".
2. Crie um projeto (nome livre, senha do banco à sua escolha, região próxima).
3. Aguarde o projeto ficar pronto.


2) CRIAR A TABELA
-----------------
1. No painel do Supabase, abra o menu "SQL Editor".
2. Clique em "New query".
3. Copie TODO o conteúdo do arquivo "supabase.sql" e cole no editor.
4. Clique em "Run".
5. Confirme que aparece a mensagem de sucesso.

(Não precisa mexer em "Storage" — o código já salva as imagens na tabela.)

IMPORTANTE (destaque em tempo real): o arquivo supabase.sql também cria a
coluna "destaque" na tabela de atividades. Se você já tinha rodado a versão
antiga, abra o SQL Editor do Supabase, cole o supabase.sql atualizado e dê
"Run" de novo: ele adiciona a coluna sem apagar nada.


3) COLOCAR AS CHAVES NO SITE
----------------------------
1. No painel: menu lateral  Settings  >  API  (ou "Project Settings > API").
2. Copie o "Project URL"  (ex.: https://uqlxneixpfsohzlyfmir.supabase.co).
   IMPORTANTE: é só o endereço, SEM "/rest/v1" no final.
3. Copie a chave pública "anon public" (a segunda chave da lista).
4. Abra o arquivo  supabase-config.js  no projeto e preencha:

   const SUPABASE_URL = "https://uqlxneixpfsohzlyfmir.supabase.co";
   const SUPABASE_ANON_KEY = "sua-chave-anon-aqui";

   (sem "/rest/v1" e sem espaços extras)


4) PUBLICAR NO GITHUB PAGES
---------------------------
1. Envie (git push) todos os arquivos para o repositório.
2. No GitHub: repo > Settings > Pages.
3. Em "Source" escolha "Deploy from a branch" > branch "main" > pasta "/ (root)".
4. Salve. Em alguns minutos o site estará no ar em:
   https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/

5. Acesse pelo link, faça login (jusantos / 123) e cadastre as atividades.


DICAS
-----
- O login funciona offline (fallback local): jusantos/123 ou prof@gmail.com/1234.
- A imagem é reduzida automaticamente antes de ser salva, para não pesar no banco.
- Qualquer pessoa que visitar o site verá as atividades cadastradas.
